# Evidencias de ejecución

baseline contiene resultados originales de Python y HTTP local, sin Docker y sin inferencia LLM real. Sus fechas están en UTC. La copia conserva los valores originales y el hash del corpus.

generated recibe tus nuevas ejecuciones y está excluido de Git. package_evidence.py empaqueta esa carpeta para incorporar evidencia posterior revisada. No alteres baseline para presentar como realizadas acciones pendientes.

No hay evidencia original de Docker, GitHub Actions, nube, navegador ni LLM real. Las simulaciones del adaptador están identificadas en unittest.json.
