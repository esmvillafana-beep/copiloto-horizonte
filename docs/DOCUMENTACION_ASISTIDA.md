# Registro de documentación asistida

Herramienta empleada para esta Fase II: ChatGPT. No se declara uso de Microsoft Copilot en esta fase.

Propósito: apoyar la estructura del código, la explicación de variables y comandos, la redacción académica y la revisión de consistencia. Los resultados ejecutados se guardan por separado; la salida de IA no es evidencia de ejecución.

Prompt de reproducción propuesto:

> Revisa este Dockerfile, contrato de API y manual de despliegue. Identifica inconsistencias entre variables, puertos y comandos. Diferencia capacidades implementadas, pruebas ejecutadas y verificaciones pendientes. No inventes capturas, métricas, enlaces ni resultados.

Criterios aplicados: contraste entre archivos y comandos; referencias oficiales; separación entre recuperación léxica y semántica; diferenciación entre inferencia real y simulación; revisión de redacción, lógica y ortografía; prohibición de incluir secretos en los reportes.

La estudiante debe reproducir los pasos, entender los límites y revisar las respuestas generativas antes de entregar. Este archivo documenta el apoyo utilizado; no representa un registro de interacción con Copilot.
